# Bb — 국내 주식 퀀트 자동매매

일봉 기준으로 4개 전략을 시장 국면에 따라 섞어 운용하는 프로그램입니다.
현재 단계는 **백테스트 + 모의매매**이고, 실계좌 주문은 연결 지점(`quant/broker.py`)만 있습니다.

## 구조

| 전략 | 내용 | 주기 |
|---|---|---|
| momentum (추세추종) | 12-1개월 수익률 상위 + 120일선 위 | 월 1회 |
| meanrev (평균회귀) | 200일선 위 종목의 RSI(2) 과매도 매수, 5일선 회복 시 청산 | 매일 |
| factor (팩터) | 중기 모멘텀 + 저변동성 + 단기 반전 순위 합성 | 월 1회 |
| breakout (변동성 돌파) | 시가 + 0.5 x 전일 변동폭 돌파 매수, 다음 날 시가 청산 | 매일 |

전략 간 비중은 고정이 아닙니다.

1. **시장 국면**: KODEX 200의 50/200일선과 변동성으로 상승·중립·하락 x 안정·고변동성을 나누고,
   국면마다 전략 배분과 현금 비중을 바꿉니다 (하락장에서는 추세추종을 끄고 현금을 늘림).
2. **성과 기울기**: 최근 6개월 성과가 좋은 전략의 비중을 키우고 나쁜 전략은 줄입니다.

신호는 당일 종가까지의 정보로만 만들고 다음 거래일 시가에 체결합니다. 수수료·거래세·슬리피지를 반영합니다.

## 사용법

```bash
pip install -r requirements.txt
python -m quant backtest                 # 과거 검증 → out/backtest/ 에 결과와 차트
python -m quant paper                    # 모의매매: 장 마감 후 하루 한 번 실행
python -m quant paper --reset            # 모의매매를 오늘부터 다시 시작
python -m quant fills                    # 장중 확인: 오늘 지금까지 체결된 모의 주문
python -m pytest                         # 테스트 (네트워크 불필요)
```

`paper`는 처음 실행한 날을 시작일로 기록하고, 이후 실행할 때마다 실제 시세로 가상 체결을 재현해
보유 종목·오늘 체결·다음 거래일 주문 예정을 보여줍니다. 장중에 실행하면 당일 봉이 미완성이라 결과가 바뀝니다.

종목, 자본, 비용, 전략 파라미터, 국면별 배분은 모두 `config.yaml`에서 바꿉니다.

## 백테스트 결과 (2016-01 ~ 2026-11-19, 비용 반영)

| | 전략 | KODEX 200 |
|---|---|---|
| 연환산수익률 | 11.4% | 13.9% |
| 연변동성 | 13.8% | 25.8% |
| 샤프지수 | 0.88 | 0.65 |
| 최대낙폭 | -28.1% | -47.4% |

전략별로 따로 돌리면 (자본 100% 배정 시): momentum 연 32.0%, meanrev 8.1%, factor 8.5%, **breakout -12.0%**.
변동성 돌파는 대형주 일봉에서 거래세·수수료를 넘지 못했습니다. `config.yaml`의 `allocations`에서
breakout을 0으로 두면 꺼집니다.

## 결과를 읽을 때 주의할 점

- **생존편향**: 유니버스가 현재 시점의 대형주 50개입니다. 과거에 크게 오른 종목이 이미 포함되어 있어
  특히 momentum 성과가 실제보다 좋게 나옵니다.
- 벤치마크 KODEX 200은 분배금을 뺀 가격이라 실제보다 조금 낮게 나옵니다.
- 변동성 돌파는 일봉의 고가로 체결을 가정합니다. 실제 장중 체결가는 다를 수 있습니다.
- 팩터 전략은 가격 기반 팩터만 씁니다. PER·PBR 같은 재무 팩터는 데이터 소스를 추가해야 합니다.
- 자본이 작으면 1주 단위 반올림 때문에 목표 비중보다 덜 담깁니다.
- 과거 성과는 미래 수익을 보장하지 않습니다.

## 일일 리포트와 자동 실행

`python -m quant paper`를 실행할 때마다 Word 리포트가 만들어집니다.

- 바탕화면의 `모의매매_리포트.docx`: 항상 같은 이름으로 최신본이 덮어써집니다 (`config.yaml`의 `paper.desktop_copy`).
- `out/paper/모의매매_리포트_날짜.docx`: 날짜별 보관본. 전체 거래내역은 같은 폴더의 `.xlsx`에 있습니다.

Windows에서 평일 장 마감 후 자동으로 실행하려면 한 번만 등록합니다.

```bash
python -m quant schedule                # 평일 15:50 자동 실행 등록
python -m quant schedule --time 16:10   # 시각 변경
python -m quant schedule --remove       # 해제
```

그 시각에 PC가 꺼져 있었으면 다음에 켰을 때 실행됩니다. 바탕화면 리포트가 Word에 열려 있으면 갱신되지 않으니 보고 나서 닫아 두세요.
