# 마이클락 : 내 자산 시계 — 앱 개발 기획서

> 증권 앱이나 코인 거래소 앱을 열지 않아도 **위젯, 잠금화면, 손목 위 시계**에서 내 주요 자산의 시세와 등락을 바로 확인하는 앱.

- 작성일: 2026-10-16
- 대상 플랫폼: iOS, iPadOS, watchOS (1차) → Android, Wear OS(갤럭시워치) (2차)
- 핵심 가치: "시계를 보듯 자산을 본다"

> ⚠️ 이 문서의 비용과 일정은 2026년 국내 시장 기준 **추정치**입니다. 시세 데이터 라이선스와 마이데이터 관련 비용은 계약 조건에 따라 크게 달라지므로 반드시 견적을 직접 받아야 합니다.

## 1. 제품 정의

### 1.1 타깃 사용자
| 페르소나 | 특징 | 핵심 니즈 |
|---|---|---|
| 직장인 투자자 | 업무 중 증권 앱을 자주 열기 어려움 | 위젯과 워치로 슬쩍 확인 |
| 멀티 자산 보유자 | 국내 주식, 미국 주식, 코인을 여러 앱에 분산 보유 | 한 화면에서 원화 기준 총자산 확인 |
| 코인 투자자 | 24시간 시장, 급변동 | 급등락 알림, 잠금화면 실시간 표시 |

### 1.2 핵심 기능 (MVP)
1. **관심 종목 시세**: 비트코인, 이더리움, 삼성전자, SK하이닉스, 애플, 엔비디아 등
2. **홈 화면과 잠금화면 위젯**: 소/중/대 크기, 잠금화면 원형/직사각형
3. **애플 워치 앱과 컴플리케이션**: 시계 화면에 BTC +2.3% 같은 형태로 표시
4. **라이브 액티비티 / 다이내믹 아일랜드**: 장중 실시간 시세 상단 고정
5. **등락 알림**: 목표가 도달, ±N% 급변 알림
6. **내 자산(수동 입력)**: 보유 수량과 평단가를 입력해 평가손익 계산 (계좌 연동 전 단계)

### 1.3 확장 기능 (v2 이후)
- 실제 계좌 연동 (증권사와 거래소)
- Android, Wear OS(갤럭시워치) 버전
- 유료 구독 기능

## 2. 기술적으로 꼭 알아야 할 제약

아이디어의 핵심인 "실시간"은 플랫폼마다 구현 방식이 다릅니다. 기획 단계에서 반드시 반영해야 합니다.

| 화면 | 실시간 가능 여부 | 구현 방법 |
|---|---|---|
| 앱 내부 | ✅ 실시간 | WebSocket으로 틱 단위 갱신 |
| iOS 홈/잠금 위젯 | ⚠️ 제한적 | WidgetKit 타임라인. 시스템이 하루 갱신 횟수(대략 수십 회)를 제한하므로 **수 분~15분 단위** 갱신이 현실적 |
| 라이브 액티비티 / 다이내믹 아일랜드 | ✅ 준실시간 | 서버에서 APNs 푸시로 업데이트. "실시간 위젯" 경험은 이 기능으로 구현 |
| 애플 워치 컴플리케이션 | ⚠️ 제한적 | WidgetKit 기반, 위젯과 비슷한 갱신 한도. 워치 앱을 열면 실시간 |
| Android 위젯 | ⚠️ 제한적 | 기본 주기 최소 30분. FCM 푸시와 WorkManager로 보완 |
| Wear OS 타일/컴플리케이션 | ⚠️ 제한적 | 갱신 요청 가능하나 배터리 정책상 제한 |

**결론**: 위젯과 워치는 "최근 시세 + 갱신 시각"을 명확히 표시하고, 진짜 실시간이 필요한 순간은 **라이브 액티비티**와 **앱 내부**로 해결하는 설계가 맞습니다.

### 2.1 시세 데이터 확보 (가장 중요한 비용 변수)
| 자산 | 데이터 소스 후보 | 비고 |
|---|---|---|
| 국내 코인 | 업비트, 빗썸 공개 API | 무료, WebSocket 제공. 이용약관의 재배포 조건 확인 필요 |
| 해외 코인 | 바이낸스, 코인베이스 공개 API | 무료 |
| 미국 주식 | Finnhub, Twelve Data, Alpaca, Polygon 계열 등 | 개인용은 저렴하지만 **앱 사용자에게 재배포하는 상업용 실시간 데이터는 별도 라이선스와 거래소 비용** 발생 |
| 국내 주식 | 한국투자증권 KIS Open API, 키움 REST API, LS증권 Open API, 코스콤 시세 | 증권사 API는 원칙적으로 **본인 계좌용**. 다수 사용자에게 실시간 시세를 제공하려면 KRX/코스콤 시세 재배포 계약이 필요 |
| 환율 | 한국수출입은행 API, 상용 FX API | 원화 환산용 |

**현실적인 전략**
- 1단계: 코인은 실시간, 주식은 **지연 시세(15~20분)** 또는 무료/저가 소스로 출시해 초기 비용을 줄임
- 2단계: 사용자가 많아지면 상용 실시간 시세 라이선스 계약
- 대안: 사용자가 자기 증권사 Open API 키를 직접 등록하는 "BYOK(Bring Your Own Key)" 방식. 본인 데이터라 재배포 이슈가 줄지만 사용 난도가 높음

### 2.2 실제 계좌 연동 방식
| 방식 | 장점 | 단점 |
|---|---|---|
| **마이데이터(본인신용정보관리업) 직접 허가** | 증권사와 거래소 자산을 정식으로 통합 조회 | 금융위원회 허가, 자본금, 보안 인프라, 심사 기간이 필요해 개인이나 초기 스타트업에게는 매우 어려움 |
| **마이데이터 사업자와 제휴** | 허가 없이 연동 가능 | 제휴 협상과 이용료 발생 |
| **증권사 Open API (사용자 키 등록)** | 비용이 낮고 빠름 | 지원 증권사가 제한적이고 사용자가 키를 발급받아야 함 |
| **거래소 읽기 전용 API 키** (업비트 등) | 코인 잔고 연동이 쉬움 | 키 보관 보안 책임이 큼. 반드시 조회 권한만 허용하도록 안내 |
| **수동 입력 + CSV 가져오기** | 규제 부담 없음 | 자동 동기화 아님 |

**권장 순서**: 수동 입력(MVP) → 코인 거래소 읽기 전용 키 → 증권사 Open API → 사용자 규모가 생기면 마이데이터 제휴.

### 2.3 법률과 규제 체크리스트
- **개인정보보호법**: 개인정보 처리방침, 최소 수집, 암호화
- **신용정보법**: 계좌 정보를 통합 조회하면 마이데이터 규제 대상이 될 수 있음 → 출시 전 금융 전문 변호사 자문 권장
- **자본시장법**: 종목 추천이나 매매 신호를 유료로 제공하면 유사투자자문업 신고 대상이 될 수 있음 → 앱은 "정보 표시"에 한정하고 투자 권유 표현 금지
- **시세 데이터 이용약관**: 재배포, 상업적 이용, 출처 표시 조건 준수
- **App Store 심사**: 금융 앱은 개인 개발자 계정보다 **법인 계정**으로 등록하는 것이 유리

## 3. 추천 기술 스택

애플 디자인과 잘 맞는 앱이 목표이고, 위젯/워치/라이브 액티비티는 어차피 네이티브 코드가 필요하므로 **iOS는 네이티브(SwiftUI)**를 권장합니다.

| 영역 | 기술 |
|---|---|
| iOS / iPadOS / watchOS | Swift, SwiftUI, WidgetKit, ActivityKit(라이브 액티비티), App Intents(시리, 단축어, 인터랙티브 위젯), Swift Charts |
| Android / Wear OS | Kotlin, Jetpack Compose, Glance(위젯), Wear OS Tiles와 Complications |
| 백엔드 | 시세 수집 서버(Node.js/TypeScript 또는 Go), Redis(최신 시세 캐시), WebSocket 팬아웃, APNs/FCM 푸시 서버 |
| 데이터베이스/인증 | PostgreSQL, Supabase 또는 Firebase(인증, 사용자 설정), Sign in with Apple |
| 인프라 | AWS 또는 GCP(서울 리전), Cloudflare |
| 보안 | iOS 키체인, Face ID 잠금, API 키 서버측 암호화(KMS) |
| 분석/운영 | Firebase Crashlytics, TelemetryDeck 또는 Amplitude, RevenueCat(구독 관리) |

### 3.1 시스템 구조
```
[업비트/바이낸스/주식 시세 API]
          │  (WebSocket/REST)
          ▼
   [시세 수집 서버] ──► [Redis 최신 시세 캐시]
          │                     │
          │                     ├──► [WebSocket 게이트웨이] ──► 앱 (실시간)
          │                     ├──► [REST API] ──► 위젯 / 워치 (주기 갱신)
          ▼                     │
   [알림 엔진] ──► APNs / FCM ──► 가격 알림, 라이브 액티비티 업데이트
```

## 4. 개발 단계와 일정

| 단계 | 기간 | 주요 작업 | 산출물 |
|---|---|---|---|
| **0. 검증과 기획** | 2~4주 | 경쟁 앱 분석, 타깃 인터뷰 10~20명, 데이터 소스 견적, 상표 검색, 법률 자문 | 기획서, 기능 명세, 데이터 계약 방향 |
| **1. UX/UI 디자인** | 3~5주 | 와이어프레임 → Figma 디자인 시스템, Apple HIG 준수, 위젯/워치/다이내믹 아일랜드 화면, 앱 아이콘 | Figma 디자인, 클릭 가능한 프로토타입 |
| **2. 백엔드 구축** | 4~6주 (디자인과 병행) | 시세 수집, 캐시, WebSocket, 알림 엔진 | 운영 가능한 API 서버 |
| **3. iOS MVP** | 8~10주 | 관심 종목, 상세 차트, 위젯, 알림, 수동 자산 입력 | iOS 앱 베타 |
| **4. 워치 + 라이브 액티비티** | 3~5주 | watchOS 앱, 컴플리케이션, 다이내믹 아일랜드 | 워치 앱 |
| **5. 베타 테스트** | 3~4주 | TestFlight 50~200명, 버그 수정, 배터리와 갱신 주기 튜닝 | 출시 후보 |
| **6. 출시** | 1~2주 | App Store 심사, 랜딩 페이지, 개인정보 처리방침 | **v1.0 출시** |
| **7. Android + Wear OS** | 10~14주 | Kotlin 앱, Glance 위젯, 갤럭시워치 타일 | Android v1.0 |
| **8. 계좌 연동** | 8~16주 | 거래소 키 연동 → 증권사 API → 마이데이터 제휴 | v2.0 |

- **iOS + 워치 출시까지 약 5~7개월**
- **Android, 계좌 연동까지 포함하면 약 10~14개월**

## 6. 디자인 방향 (Apple 스타일)

- **Apple Human Interface Guidelines 준수**: SF Pro 폰트, SF Symbols 아이콘, 시스템 머티리얼(블러), 다크 모드
- **등락 색상 현지화**: 한국은 상승 빨강 / 하락 파랑, 미국은 상승 초록 / 하락 빨강 → 설정에서 선택
- **시계 콘셉트의 시각 언어**: 원형 게이지로 일간 등락률을 시계 바늘처럼 표현해 다른 앱과 차별화
- **숫자 가독성**: 고정폭 숫자(monospaced digits), 가격 변화 시 숫자 롤링 애니메이션
- **최소한의 정보 밀도**: 위젯에는 종목명, 현재가, 등락률, 갱신 시각만 표시
- **접근성**: 다이내믹 타입, VoiceOver, 색각 이상 사용자를 위해 ▲▼ 기호 병행

## 7. 생각하지 못했을 수 있는 기능 제안

### 7.1 차별화 기능
1. **자산 시계 워치 페이스**: 시계 바늘 대신 총자산 수익률이 움직이는 컴플리케이션. 앱 이름과 콘셉트를 그대로 살리는 시그니처 기능
2. **프라이버시 모드**: 금액은 숨기고 %만 표시. 회사, 지하철 등 공공장소에서 위젯을 볼 때 필수
3. **원화 통합 총자산**: 미국 주식과 코인을 실시간 환율로 원화 환산해 한 줄로 표시
4. **김치 프리미엄 표시**: 업비트와 바이낸스 비트코인 가격 차이
5. **시장 상태 표시**: 국내장/미국장 개장, 프리마켓, 애프터마켓, 휴장일 자동 표시
6. **햅틱 시세 알림 (애플 워치)**: 상승과 하락에 서로 다른 진동 패턴. 화면을 보지 않아도 방향을 알 수 있음
7. **StandBy 모드 대응**: 아이폰 충전 거치 시 탁상 시계처럼 시세 표시
8. **시리 / 단축어**: "시리야, 내 자산 얼마야?", "비트코인 시세 알려줘"
9. **인터랙티브 위젯**: 위젯에서 바로 종목 전환, 새로고침 (iOS 17 이상)
10. **제어 센터 컨트롤과 액션 버튼**: 아이폰 액션 버튼으로 총자산 즉시 확인

### 7.2 편의 기능
- **하루 브리핑 알림**: 아침 8시 "어젯밤 미국장 요약 + 내 자산 변화"
- **배당, 실적 발표 캘린더**: 보유 종목 기준 일정 알림
- **AI 뉴스 요약**: 급등락 시 "왜 올랐는지" 한 줄 요약 (투자 권유가 아닌 정보 제공으로 한정)
- **가족/커플 공유 위젯**: 공동 투자 자산 공유 (선택)
- **iPad, Mac 메뉴 막대 위젯**: 업무 중 PC에서도 확인
- **CarPlay 대시보드 위젯**: 운전 중 주요 지표만 표시 (안전 가이드 준수)

### 7.3 신뢰와 안정성
- **데이터 출처와 지연 여부 명시**: "업비트 실시간", "15분 지연" 라벨 표기
- **장애 대비 다중 데이터 소스**: 한 API가 멈춰도 다른 소스로 자동 전환
- **Face ID 앱 잠금**: 자산 정보 보호
- **조회 전용 원칙**: 거래 기능을 넣지 않아 보안 부담과 규제 부담을 줄이고 "가장 안전한 자산 조회 앱"으로 포지셔닝

## 8. 개선점과 리스크

| 리스크 | 대응 |
|---|---|
| 위젯이 실시간이 아니라는 사용자 불만 | 라이브 액티비티를 핵심 기능으로 홍보, 위젯에 갱신 시각 표시 |
| 시세 데이터 비용 급증 | 코인 우선 출시, 주식은 지연 시세 무료/실시간 유료로 구분 |
| 계좌 연동 규제 | 수동 입력과 읽기 전용 키로 시작, 이후 제휴 |
| 기존 증권 앱 위젯과 경쟁 | **여러 증권사와 거래소를 한 위젯에** 통합하는 것이 핵심 차별점 |
| 배터리 소모 | 갱신 주기를 사용자가 선택, 장 마감 시 자동 절전 |
| 앱 이름 상표 충돌 | KIPRIS에서 "마이클락", "MyClock", "MyClack" 검색 후 출원 |

## 9. 앱 이름과 브랜딩

- **앱 스토어 이름**: 마이클락: 내 자산 시계 (App Store 앱 이름은 30자 이내)
- **부제(서브타이틀) 예시**: 위젯과 워치로 보는 실시간 시세
- **영문 표기 후보**: MyClock / MyClack — "Clock(시계)"과 시세가 똑딱이는 소리 "Clack"의 중의적 의미를 활용 가능. 단, 영문 "MyClock"은 일반 단어 조합이라 상표 등록과 검색 노출이 어려울 수 있어 **고유한 영문 표기**를 권장
- **할 일**: KIPRIS 상표 검색 → 도메인(myclock.kr 등) 확보 → App Store / Google Play 이름 선점
